Komponen kartu visual yang mewakili stasiun kerja/proses pabrik di canvas.

Elemen Visual UI:
Header Card: Judul/Nama Proses (misal: "Stasiun Jahit A" atau "Cutting").
Badge/Tag Skill: Menampilkan daftar keahlian yang dibutuhkan (misal: ["Sewing", "Assembly"]).
Target Output / Kapasitas: Angka atau indikator singkat kapasitas kerja.
Titik Konektor (Handles): Titik di sisi kiri/kanan/atas/bawah node sebagai tempat menancapkan garis panah.
