Toolbar floating di tengah canvas bagian kiri. Komponen ini mengatur mode aksi user saat ini.

Properti / State: activeTool ('select', 'add-fabric', 'add-worker', 'connect', 'erase', 'undo').

Fitur UI:

Cursor / Select: Mode standar untuk memilih dan menggeser node.

Tambah Node Proses (Pabrik): Mengubah cursor agar saat canvas diklik, node proses baru langsung muncul.

Tambah Node Pekerja: Mengubah cursor agar saat canvas diklik, node pekerja baru langsung muncul.

Connect (Hubungkan): Mode untuk menghubungkan node A ke node B.

Erase / Hapus: Mode untuk mengeklik elemen di canvas yang ingin dihapus.

Undo / Redo: Tombol aksi langsung untuk membatalkan/mengulang perubahan.
